# Support

MCPserver.in is a public information service — there is no live chat or
support team. Pick the channel that matches your need:

| Need | Channel |
| --- | --- |
| Bug or wrong content on a published page | GitHub issue (`bug` template) |
| Coordinated security disclosure | security@mcpserver.in |
| New pillar or editorial entry proposal | GitHub issue (`feature_request` template) |
| Verification of a specific server's status | email security@mcpserver.in with the slug |
| General "how do I…" question | [`/troubleshooting`](https://www.mcpserver.in/troubleshooting) or [`/learn`](https://www.mcpserver.in/learn) |

## Response SLAs

- Bug acknowledgement: 7 days (best-effort; not a paid product)
- Security: see `SECURITY.md`
- Editorial proposals: 14 days; many will be deferred until verification
  evidence is available

This project does not offer paid support, 1:1 help, or live assistance.
